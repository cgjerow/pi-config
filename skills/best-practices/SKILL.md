# Best Practices Skill

Provides best practices, conventions, and recommendations for a given technology, framework, or language.

## Usage

Specify the technology, framework, language, or topic. The skill will cover:

1. **General principles** — Widely accepted best practices
2. **Language/framework specifics** — Idiomatic patterns and conventions
3. **Common pitfalls** — What to avoid
4. **Tooling** — Recommended linters, formatters, testing tools
5. **Project structure** — Common directory layouts

## Output Format

```markdown
## General Principles
- [Principle 1]
- [Principle 2]

## Language/Framework Specifics
- [Convention 1]
- [Convention 2]

## Common Pitfalls
- [Pitfall 1]: [What to do instead]
- [Pitfall 2]: [What to do instead]

## Recommended Tooling
- **Linting:** [Tool]
- **Formatting:** [Tool]
- **Testing:** [Tool]

## Project Structure
```
recommended/
structure/
```
```

## Tips

- Be specific to the version/ecosystem the user is working with
- Include links to official docs where helpful
- Prioritize practices by impact
