# Explain Skill

Explains code, functions, classes, or error messages in clear, accessible language.

## Usage

Provide the code block, function, or error you want explained. The skill will break it down into:

1. **What it does** — Plain-language summary
2. **How it works** — Step-by-step explanation
3. **Key concepts** — Important patterns, APIs, or techniques used
4. **Edge cases** — Any gotchas or unusual behavior

## Output Format

```
## What It Does
[Plain language summary]

## How It Works
1. [Step 1]
2. [Step 2]
...

## Key Concepts
- [Concept 1]
- [Concept 2]

## Edge Cases
- [Edge case if any]
```

## Tips

- Adjust depth based on the user's apparent expertise level
- Use analogies for complex concepts
- If explaining an error, include how to fix it
