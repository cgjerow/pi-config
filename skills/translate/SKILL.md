# Translate Skill

Translates code, comments, or documentation between languages.

## Usage

Provide the source material and target language. The skill will:

1. Preserve semantics and intent
2. Follow idiomatic patterns of the target language
3. Adapt to ecosystem conventions

## Output Format

```
## Translated Code
[Code in target language]

## Notes
- [Key differences or adaptations]
- [Package/library equivalents if applicable]
- [Caveats or gotchas]
```

## Tips

- This isn't just syntax translation — adapt to idiomatic patterns
- Consider performance implications of the translation
- Note any functionality that doesn't have a direct equivalent
